# Prototype walkthrough

## Navigation map

| Route | Sequence | Completion state |
| --- | --- | --- |
| Primary founder | Welcome → Workspace → Plans → Review → First task | Demo setup confirmed; first useful action separately demonstrated |
| Plan evaluator | Welcome Compare plans → all-options comparison → Workspace → Plans → Review → First task | User can choose before answering detailed setup questions |
| Team member | Welcome Joining a team → Workspace member role → Plans → Review request → First task | Admin approval remains pending; sample task may be completed |
| Optional Enterprise branch | Plans Enterprise requirement → model an existing Cloud account or select Business | No Cloud purchase or provisioning is implied |
| Recovery | Back / available progress step / Edit → change one answer → review again | Other answers persist; old confirmation is invalidated |

## Two to three minute narration

**0:00–0:20 Welcome.** “This is our unofficial research prototype for teams under 10 developers. Our notes show that some people wanted guidance while others found required chat excessive. The main route is a direct setup, and help is available on the side.” Click Start setup.

**0:20–0:45 Workspace.** “We ask who is building and what they can manage. A fictional team can use an existing workspace or name a new one. The organization definition is beside the question. Advanced access needs are optional, so we do not ask every founder about enterprise identity setup.” Keep My team, three people, and demo owner. Click See plans.

**0:45–1:20 Plans.** “The notes ask for alternatives, prices, and reasons. Business is suggested with visible reasons, and Enterprise’s separate prerequisite is clear. All listed options are available through comparison, including the individual Free baseline. This number is a seat estimate from a dated official snapshot, not a real purchase.” Decrease selected seats from three to two; show the estimate changing from $57 to $38. Briefly open all plan options, then close. Click Review setup.

**1:20–1:45 Review.** “A user can edit one answer without repeating everything. Material edits require reviewing the setup again. Seats are separate from invitations, and fictional assignments are only planning examples. We preserve an explicit access review because one participant liked speed but wanted more company-level clarity.” Check the access acknowledgment and confirm.

**1:45–2:20 First action.** “Setup complete and useful value are different milestones. This example uses a prepared diff. It is not calling a model or touching a real project.” Run demo task, explain the empty-name fallback, check the review box, accept, and record the demo commit.

**2:20–2:45 Finish and alternatives.** “This result records a simulated milestone only. A plan evaluator can enter through comparison. A non-admin gets a draft request and stays pending, while still being able to try a sample task. The design is a hypothesis for our team to test, not a measured improvement yet.”

## Manual recording instructions

No video recording API was available in the supported browser interface, so no automatic recording is claimed. To produce the required real recording on a teammate’s Mac:

1. Start the app with the README instructions and open it in a browser at a laptop-sized window.
2. Reset demo and close unrelated tabs and notifications.
3. Press **Shift+Command+5**, choose **Record Selected Portion**, select the browser region, and choose a microphone if narrating.
4. Start recording and follow the primary narration above. Keep the demo-only labels visible.
5. Stop with the menu-bar stop control. Play the saved recording and verify the complete primary route, readable text, and audio.
6. Save as `copilot-express-primary-walkthrough.mov`, or export an MP4 using a supported editor. Keep it outside the source repository.
7. Add any team edits and actual attribution before uploading it to the verified new homework folder. No upload is performed by these instructions.

If live narration is not feasible, record the real clicks and add the same narration afterwards. Do not substitute a generated video for a recording of the working prototype.
